# StockFlow AI web app

Vercel-ready browser client for viewing the shop's cloud-synced products, inventory, sales, customers, documents, and reports. The current main PC backs up to the cloud one way, so the browser is read-only; the backend also rejects browser uploads. POS and inventory changes stay on the desktop until a two-way cloud relay has been built and verified.

Start with [the Vercel deployment guide](../docs/WEB_DEPLOYMENT.md). Use a distinct browser device identity; never copy the desktop device ID.
