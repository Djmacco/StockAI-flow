# StockFlow AI web app

Vercel-ready StockFlow AI browser app. A cloud administrator can open **Company sales** to view the business's synced transactions directly from the hosted backend, including phone-friendly receipts and printable filtered reports. The existing first-use flow can still restore a read-only copy of the full cloud snapshot. The current main PC backs up to the cloud one way, so browser inventory and POS edits remain disabled until a safe two-way relay is available.

Start with [the Vercel deployment guide](../docs/WEB_DEPLOYMENT.md). Use a distinct browser device identity; never copy the desktop device ID.
